## 六、别再踩的坑（完整 8 条见《接入现状》第五章）

- Windows CLI 读 stdin 会挂死（登录类命令相反，要保活）
- 后台进程要 `powershell Start-Process` 真正脱离，否则被回收
- Git Bash 改写 `/` 开头的参数 → `MSYS_NO_PATHCONV=1`
- npm 全局 CLI 是 `.cmd` 垫片 → 解析到真实入口再 spawn
- **账号权益 ≠ 网络**：400 权益错 ≠ 超时
- **CLI 版本会被服务端强杀**：426 → 先 update
- VPN / TUN 模式 curl 直连就通，不必配 HTTP_PROXY
- 钉钉待办列表一页 20 条、默认只返回执行人 → 要 `--role-types creator,executor,participant` 翻页
