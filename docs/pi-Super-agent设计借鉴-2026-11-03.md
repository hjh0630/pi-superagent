## 零、一句话结论

三篇是**同一内核的三条独立路径**：dsh 是工程论文（领域模型最硬），卡兹克是国内个人落地范式（中台 + 规则表 + 票拟 + CI 五步），Grok Bot 是产品级人机边界规范（最细）。交集收敛出 **8 条设计公理**；我们**照抄公理、不抄他们的组织形态**（他的云端中台、xAI 的云电脑都因为"我们本机直连 + 全本地"而不需要）。

## 二、8 条设计公理（我们的地基）

1. **瓶颈是人的注意力**，不是模型能力 → 验收指标是"一天只打扰你 2~3 次"。
2. **任务起点从人身上拿掉** → 事件驱动，不是人下命令。
3. **脑手分离**：决策层与执行层隔离，决策层不阻塞。
4. **默认不打扰**：只在"必须人拍板 / 有可交付成果"时开口，一次只问一个**结构化**问题。
5. **先记账后动手**：状态外置、可断点续跑、不重复不丢。
6. **权限机器可读 + 越窄越好**：不可变授权单、影子模式先记录不执行。
7. **交付要有证据**：只验收可复现的验证结果，不接受自述。
8. **本地优先、凭据不出本机**：代码、身份、浏览器会话都留在自己的机器。

### 3.2 不抄（附理由）

| 不抄的东西 | 理由 |
|---|---|
| 卡兹克的**云端中台 + 反向长轮询** | 那是因为他的 Mac 在内网、中台在公网。我们**本机直连**（钉钉/飞书/GitHub/邮件/手机全在本机），不需要中转层。抄的是"统一格式 + 规则表 + 去重 + 数据沉淀"，不是"把中台放云上"。 |
| Grok Bot 的**云电脑** | 在美国机房、无你的本地凭据、官方自认"不擅长在本地项目目录做长编码"——而那正是我们的战场。 |
| Muse / Grok App / DeepSeek App 作为执行器 | 无公开 API/CLI，只能当触发器或通知器；Grok 的可编程件是本机 `grok agent serve/leader`。 |
| 用弱模型当 Router/裁决 | 卡兹克明确反对（"不能用笨逼指挥聪明的"）。 |
| WorkBuddy 账号反代 | 逆向、违反 ToS、有封号风险、凭据必须进模型可达范围（同时踩 Anthropic 安全红线）。 |
| 影子模式（dsh 自己也还在蓝图） | 先预留 Policy 版本号 + Mandate 签名的位置，不实现。 |
| 卡兹克的规模（1000 PR/月、自建 CI 中台） | 我们是单人/小团队，只抄"五步"的结构，不抄复杂度。 |
| 云端 dsh-superagent 直接当依赖 | 官方声明"研究原型、非官方产品"，只抄领域模型，在 pi 上重写实现。 |

## 四、我们的三个关键设计（融合三篇后的新增）

### 4.1 分级自主 L0–L3（让"自主"与"安全"不冲突）

| 级别 | 含义 | 例子 | 默认 |
|---|---|---|---|
| L0 观察 | 只读、不留外部痕迹 | 读仓库、抓竞品、查资料 | 自动 |
| L1 起草 | 生成产物供人取用 | 文案、方案、代码草稿 | 自动 |
| L2 可逆执行 | 能撤销的写操作 | 建分支/提 PR/写平台草稿箱/改本地配置 | 自动 |
| L3 不可逆或对外 | 发布、合并主干、花钱、发帖私信、删数据、轮换密钥 | 上线、投放、群发 | **必须审批** |

**批量授权窗口**（三篇交集）：agent 先产出 7 天内容排期 → 人一次性审批这批 → 之后按排期自动执行，中途可一键暂停。
= Grok Bot 的 `Always allow` + 卡兹克的 7 类红线 + dsh 的 Mandate scope。

### 4.2 双通道汇报（解决"30 分钟心跳"与"注意力纪律"的冲突）

| 通道 | 内容 | 是否要求回应 | 频率 | 成本 |
|---|---|---|---|---|
| **流水通道**（钉钉群 / pi-reach 日志流） | 30 分钟**模板化快照**：本时段完成/在跑/待审批/花钱/风险 | ❌ 不要求，可折叠、不升级强通知 | 48/天 | **零 token**（只读账本） |
| **决策通道**（钉钉卡片 / pi-reach 置顶） | 12 小时**进展 + 下 12 小时计划**（带批准/修改按钮） | ✅ 要求点一次 | 2/天 | 2 次模型调用 |

**"下 12 小时的计划"必须落成可批准的 12 小时任务窗口**（一批带预算/验收/授权范围的 Assignment），而不是一段漂亮话——这样计划有约束、有预算、有验收。

### 4.3 两级执行器与模型分工

| 级别 | 形态 | 能力 | 成本 | 适合 |
|---|---|---|---|---|
| **T1 API 级** | pi 原生 provider（OpenAI 兼容）：DeepSeek / xAI / Kimi / 通义 / 智谱 / OpenRouter | 只做推理与文本，**不改文件不跑命令** | 低、快、可高并发 | 调度、拆解、验收、文案、裁决 |
| **T2 CLI 级** | pi-model-fleet：codex / claude / grok / gemini(agy) / pi | **真 agent**：改代码、跑测试、用工具、提 PR | 高、慢 | 编码、审查、长任务 |

原则（卡兹克）：**做决策和管理的模型必须最强**；Flash 级只做提取类杂活。**超集不是"堆模型"，而是"按能力分层调度 + 证据裁决"。**
